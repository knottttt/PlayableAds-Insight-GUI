Notes
· 工具仅在浏览器本地运行，不会上传 playable 或素材
· 当前支持识别 window.__zip、window.__res、__adapter_zip__ 和部分 inline data:image 场景
· ZIP 内图片替换后会自动重新压缩回写，尽量避免生成文件体积异常变大
· adapter_zip 模式通过运行时 override 生效；如素材未即时变化，建议重新打开页面验证
· 工具会统一重写常见商店链接，包括 itunes.apple.com、apps.apple.com、play.google.com/store/apps、部分内嵌 ZIP 内链接和 mraid / window.open 兜底逻辑
· 生成后支持直接在面板里本地预览；最终仍建议下载 HTML 抽查页面展示、首屏素材、点击跳转和文件体积
· 使用过程中如遇问题，请在 GitHub 留言提交反馈
· 免责声明：本工具仅供学习交流，禁止用于任何商业用途
